# vidzcuts

Portfolio website for video editor **Moizza Fatima**, with an admin dashboard to manage videos and content.

- Public site: hero, work (Motion graphics / B-roll / Ads, YouTube videos that play on hover), services, about, contact.
- Dashboard at `/admin`: add/edit/reorder/hide videos, edit text and contact details, change login.
- Next.js + Tailwind + Neon Postgres, deployed on Vercel.

See [DEPLOY.md](DEPLOY.md) for setup and deployment.
